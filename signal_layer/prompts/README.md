This directory contains the prompt artifacts used by the HTM signal layer. It includes both the manually written seed prompts and the prompts generated by GEPA during optimization.

## Prompt files

### Seed prompts

These are the hand-written starting points for GEPA.

| File | Description |
|------|-------------|
| `student_seed.txt` | Seed prompt using the trust-state memory protocol. |
| `student_seed_summary.txt` | Seed prompt using the rolling summary memory protocol. |

### Optimized prompts

These files are generated automatically by `python -m signal_layer.main --stage optimize` and should not be edited manually.

| File | Description |
|------|-------------|
| `student_optimized_summary.txt` | GEPA-optimized prompt used by the signal layer. |
| `student_optimized_summary.json` | Serialized DSPy program produced during optimization (generated artifact). |

The prompt loaded at inference time is selected by the `artifact` field in `signal_layer/config/gepa.yaml`.

## Trust dynamics (experimental)

The optional trust-dynamics optimization (`signal_layer/optimize/`) uses:

| File | Description |
|------|-------------|
| `dynamics_seed.txt` | Seed implementation of the HTM trust dynamics used for experimental code evolution. |

This optimization is experimental and is not used in the published results.

## Notes

- Reflection prompts are provided internally by DSPy and are not stored in this repository.
- Evaluation outputs are written to `signal_layer/evals/runs/`, not this directory.
- Generated prompt artifacts can always be regenerated by rerunning the optimization pipeline.
